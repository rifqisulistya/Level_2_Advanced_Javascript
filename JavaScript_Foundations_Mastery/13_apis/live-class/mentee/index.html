🌐 APIs — How the Web Talks to Itself

Lesson 12

HTTP Methods

GET Read / fetch data POST Create new data PUT Update existing data DELETE Remove data

Status Codes

200 OK — success
201 Created — new resource made
400 Bad Request — your data is wrong
401 Unauthorized — not logged in
403 Forbidden — logged in, no permission
404 Not Found — resource doesn't exist
500 Server Error — their problem, not yours

Query Parameters

/posts?userId=1
/weather?lat=40&lon=-74
/search?q=cats&limit=10
/posts?_page=2&_limit=5

Start with ? — separate pairs with &
